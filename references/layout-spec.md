> 这份文件是「做对了长什么样」的唯一标准。换类目、换站点只改第 1 节参数，其余不要动。

## 2. 数据字段（每个商品 8 个）

| 字段 | 来源 | 规则 |
|---|---|---|
| 排名 rank | 榜单页 `.zg-bdg-text` | 1–100，自然位次，非搜索排名 |
| ASIN | 榜单页商品链接 `/dp/([A-Z0-9]{10})` | 10 位，需去重 |
| 标题 title | 榜单卡片文字（`img.alt` 兜底） | 仅在商品页无颜色属性时用于兜底，不上表 |
| 图片 img | 榜单卡片 `img.src` | 换成 `._AC_SL400_.jpg` 取清晰大图 |
| 品牌 brand | 商品页 `#bylineInfo` | 去掉 `Visit the` / `Brand:` / `Store` 前后缀 |
| 价格 price | 商品页 `a-price-whole` + `a-price-fraction` | 美元浮点，兜底见 §5 |
| 颜色原文 color_dp | 商品页 Color 字段（变体选择器 → 详情表 → detail bullets） | 亚马逊原始字符串，**一个字符都不改**；仅存证，见 §4 |
| 显示颜色 color_raw | 由 color_dp 无损清洗得到 | **卡片上显示的就是这个**，与 color_dp 逐条一致（100%）；取不到时用标题原样短语 |
| 色系 color | 由 color_raw 归组（黑/金/渐变…） | 仅用于顶部色条统计，规则见 §4 |

## 3. 表格版式（精确参数，照抄即可还原）

单工作表，表名 = 日期（如 `2026-10-21`）。**表格是卡片看板，不是普通行列表**。

**网格**
- 每行 10 张卡片，共 10 行（100 个商品），每段 6 行（5 行卡片 + 1 行间隔）
- 每张卡占 **2 列**，卡片之间空 **1 列**做留白 → 一行占用列宽 = 10×3-1 = 29 列
- 单列宽 `11.2` 字符（本机默认字体下 = **90px**），留白列宽 `1.5`
- A 列宽 `1.4` 作左边距，卡片从 **B 列**开始
- 卡片区从**第 6 行**开始；每张卡纵向占 5 行 + 1 行间隔（行高：112 / 21 / 21 / 17 / 18 / 12 pt）

**卡片内部（自上而下）**

| 行 | 内容 | 样式 |
|---|---|---|
| 1 | 商品图 | 最大 126×138px，等比缩放，水平垂直居中，白底 |
| 2 左 | `#排名` | Arial 12 加粗，前 3 名 `#C2410C`，其余 `#6B7280`，居中 |
| 2 右 | `$价格` | Arial 10.5 加粗，格式 `"$"#,##0.00`，居中，**不要设缩进**（否则列宽不足显示 `####`） |
| 3 | 品牌 | 微软雅黑 10 加粗，合并 2 列，居中 |
| 4 | **颜色（原文）** | 色点 `● `（Arial 9，颜色=色系色）+ 原文（雅黑 8.8，`#6B7280`），合并 2 列，居中，行高 17pt |
| 5 | ASIN | Arial 9，蓝色 `#0563C1` + 下划线，**超链接到 `https://www.amazon.com/dp/<ASIN>`**，合并 2 列，居中 |

- 卡片边框：细线 `#DCE1E8`，白底
- **前 3 名卡片**用 `#FF9900` 橙色描边
- 文字全部居中（左对齐会让宽卡片中间留大片空白，已确认不可接受）

**顶部信息区（第 1–4 行）**

| 行 | 内容 |
|---|---|
| 1 | 标题：`Amazon US Best Sellers · <类目名> · Top 100`（雅黑 16 加粗） |
| 2 | 榜单日期（美西）｜数据源：类目路径 + node ID｜抓取时间（北京时间/美西双标） |
| 3 | 均价 ｜ 中位价 ｜ 价格带 ｜ 品牌数 ｜ 头部品牌（含席位数） |
| 4 | **色系分布色条**：一个色系一格，格子底色=该色系，文案 `色系 数量 · 占比%`，按数量降序（标签写「色系分布」，因为卡片显示的是原文） |

**其他**
- 隐藏网格线、冻结窗格在第 6 行、横向打印、缩放适应页宽
- 底部 3 行小字说明（字段含义、价格口径、每日新表可做变动对比）

## 4. 颜色口径（完全无损，逐字照抄）

**卡片显示的就是商品页 Color 字段本身的字符串，一个字符都不改**：不改大小写、不截断、不提取短语、不删尺寸或长度前缀。

下面这些都要原样显示，即使看起来不像颜色：

```
Ash Rooted platinum blonde          1b                OFF BLACK
Small size light blue               Natural Color 1b#
Silver+Leopard+Black (Pack of 3)    200%Density 13x4 Lace Front Wig
```

**取数顺序**（`parse_color_html` / `DP_JS`）
1. 变体选择器 `#variation_color_name .selection`
2. 商品详情表 `Color` 行（`#productDetails_techSpec_section_1` / `detailBullets`）
3. 都没有 → 标题里的颜色短语（原样截取，保留原大小写）
4. 都没有 → `—`

**清洗**（`normalize_color` → `_clean_color_text`）只做无损动作：HTML 反转义、去标签、合并连续空白、去掉 `Color:` / `Colour:` 这个**字段名**前缀、去首尾标点。
**不做**：改大小写（`1b` 不写成 `1B`、`OFF BLACK` 不写成 `Off Black`）、按长度截取、删 `Small size` 前缀、删尾部 `24inch`。

**标题兜底**（`title_color_phrase`）仅当商品页没有 Color 字段时使用，从标题里原样截取颜色短语，不改写。

**判源与验收**
- `color_dp`：商品页原文（仅存证）；`color_raw`：最终显示值
- `color_src`：`dp`（页面有该字段）/ `title`（标题兜底）/ `none`（都没有）
- **验收标准：页面有 Color 字段的条目，`color_raw` 必须与 `color_dp` 逐条 100% 相同**

**色系归组**（`classify_color`，只用于顶部色条，不影响卡片显示）
先判「多色」归 `渐变 / 挑染`（`ombre / balayage / highlight / two-tone / mixed color / colorful / rainbow / black and white / X to Y`），
再按出现位置最靠前归入：白/银 → 黑（含 `1b`、`natural color`）→ 金 → 棕 → 红/酒红 → 粉 → 紫 → 蓝 → 橙 → 绿，都不中则 `其他 / 未标注`。
占比取整后若合计 ≠ 100，差额补给数量最多的那一类。

**为什么这条规则写得这么死**：它被改坏过两次。
- v1（≤2026-11-06）用 `len(v) > 24` 触发短语提取，把 `Ash Rooted platinum blonde` 截成 `Platinum Blonde`，还抹掉了 `Brown Mix Blonde Highlights` 的挑染信号
- v2（2026-11-09 下午）取消截断，但仍逐词改大小写，与原文每天仍有 19~21 条不一致
- v3（当前）完全无损

## 5. 价格口径与兜底

优先级从高到低：
1. 商品页实时售价（USD）——主口径
2. 商品页不显示价格时（常见原因：`This item cannot be shipped to your selected delivery location`），用**榜单卡片价**兜底，并在数据里标记 `price_src=grid`
3. 两者都没有 → 价格列填 `0` 并在说明里注明（正常不会发生）

> 榜单卡片价与商品页价同源，差异通常在 0–1 美元内，可以混用但必须标记来源。

## 6. 验收标准（不通过就不算完成）

1. 表名 = 日期，**只有一个**工作表
2. 100 张卡片，排名 1–100 **无缺号、无重复**
3. 100 张图片全部内嵌（不是外链），无空白格
4. 100 个 ASIN 全部是超链接，点击落到对应商品页
5. 排名/价格/品牌/ASIN 全部**居中**
6. 图片相对卡片**水平居中**（用 `Shape.Left - Cell.Left ≈ (CardWidth - ImageWidth)/2` 校验，误差 < 1pt）
7. 每张卡片都有颜色（原文或 `—`），色系分布数量合计 = 100，占比合计 = 100%
8. 颜色原文来自商品页的比例应 > 95%（取不到才允许标题兜底，日志会打印 `商品页属性 N 条 / 标题兜底 M 条`）
8. 顶部三行信息完整，价格统计与卡片数据一致
9. 文件能被 Excel / WPS 正常打开，无「修复」提示
